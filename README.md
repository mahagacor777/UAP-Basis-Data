# UAP-Basis-Data
Project website sederhana berbasis PHP



project ini disusun untuk memenuhi tugas tambahan pada proyek ujian akhir praktikum (UAP) responsi matakuliah Basis Data yang berfokus pada implementasi sederhana DBMS berbasis laragon.

## Cara Memasukkan Data Dummy & Struktur DB
1. pada folder dataSQL pada repo ini terdapat file dengan ektensi .sql 
2. masuk ke phpmyadmin  
3. buat database dengan nama "simdk" pastikan tidak ada tabel satupun
4. klik db tersebut klik "import" lalu pilih file data dummmy sql ini yang ekstensinya .sql
5. scroll kebawah lalu import

## cara memasukkan tampilan web ke laragon
1. pergi ke file manager
2. cari folder laragon
3. pergi ke laragon >> www
4. hapus seluruh isi pada /www
5. pindahkan folder simdk pada repo ini (ada di dalam folder program)
